# Java Collection Framework

This repository contains examples and programs demonstrating the Java Collection Framework and Java 8 Stream API.

## Topics Covered

### List

* Remove Duplicates from List
* Find Duplicate Elements
* Find Common Elements Between Two Lists
* Find Union of Two Lists
* Find Difference Between Two Lists
* Reverse a List
* Sort List in Ascending Order
* Sort List in Descending Order
* Find Maximum Element
* Find Minimum Element

### Set

* Convert List to Set
* Find Unique Elements
* Check Element Exists in Set

### Map

* Count Frequency of Elements using HashMap
* Sort HashMap by Key
* Sort HashMap by Value
* Convert List to Map
* Merge Two Maps
* Find Key with Maximum Value
* Iterate HashMap

## Concepts

* List, Set, and Map
* ArrayList and LinkedList
* HashMap Internal Working
* HashSet and TreeSet
* Comparable and Comparator
* ConcurrentHashMap
* Fail-Fast and Fail-Safe Iterators
* Collection Time Complexities

## Technologies Used

* Java 8+
* Collections Framework
* Stream API
* Lambda Expressions

## Project Structure

Each program is organized into separate classes with examples demonstrating collection operations, sorting, searching, filtering, grouping, and data manipulation using Java Collections and Streams.
